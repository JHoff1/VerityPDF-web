# VerityPDF website

Source for the public VerityPDF product website. It presents the local-first
desktop PDF editor, links to the latest GitHub release, and documents the
project's privacy and open-source commitments.

## Local development

Requires Node.js 22.13 or later.

```bash
npm install
npm run dev
```

Run `npm test` for a production build and rendered-HTML checks.

The public deployment URL is supplied through the `URL` environment variable.
